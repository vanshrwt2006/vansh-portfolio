# Vansh Rawat — Full Stack Developer Portfolio

A professional, lightweight, and interview-ready portfolio website crafted with pure **HTML5, CSS3, JavaScript**, and **Java (Spring Boot REST API reference)**.

Designed specifically for **B.Tech Computer Science & Engineering (CSE)** students and graduates applying for **Software Development Engineer (SDE)**, **Full-Stack Developer**, and **Java Backend Engineer** positions.

---

## 🌟 Why This Portfolio Impresses Technical Interviewers

1. **Zero External Dependencies / Blazing Fast**:
   - Pure semantic HTML5 and vanilla modern CSS & JS.
   - Loads in under 50ms with no CDN latency or bundle overhead.
2. **Interview-Focused Content**:
   - Highlighting **Core Java, Spring Boot, RESTful APIs, SQL, Data Structures & Algorithms (350+ DSA solved)**.
   - Project cards structured using the **STAR methodology** (Situation, Tech, Architecture, Result).
3. **Interactive Recruiter Features**:
   - 🌓 **Dark / Light Mode Toggle** with `localStorage` memory.
   - ⌨️ **Dynamic Typewriter Effect** showcasing multiple key roles.
   - 🔍 **Interactive Project Filter Tabs** (All, Full Stack, Java/Spring, HTML/CSS/JS).
   - 📋 **1-Click Copy** buttons for email and phone with instant toast feedback.
   - 🖨️ **Print-Friendly Resume Button** (triggers clean one-click PDF save or print).

## 🚀 How to Run & Preview

### Option 1: Direct Double-Click (No Installation Required!)
Simply navigate to this folder in Windows File Explorer and **double-click `index.html`**. It will open instantly in your default web browser (Chrome, Edge, Firefox, Brave, etc.).

### Option 2: Live Server in VS Code
1. Open this folder in **VS Code**:
   ```bash
   code .
   ```
2. Right-click `index.html` and click **"Open with Live Server"**.

## 🛠️ How to Customize Your Details (In 2 Minutes)

Open `index.html` in your favorite editor and update:
1. **Name & Contact**:
   - Change `vanshrawat.cse@gmail.com` to your real email.
   - Change `+91 98765 43210` to your phone number.
2. **Social & Coding Links**:
   - Replace `https://leetcode.com` with your actual LeetCode profile handle.
   - Replace `https://github.com` with your GitHub URL.
   - Replace `https://linkedin.com` with your LinkedIn profile URL.
3. **Education & College**:
   - In the Education section, replace `University Institute of Technology` with your actual college/university name and your current CGPA.
